# Meu Primeiro PR

Este repositório existe para eu praticar o fluxo de Pull Request no GitHub, do começo ao fim, com a ajuda do Claude Code.

## Sobre

Este é um repositorio de teste criado para aprender o workflow de contribuição em projetos open source: branch, commit, push e pull request.

## Como praticar

1. Crie uma branch
2. Faça uma pequena melhoria
3. Abra um Pull Request
4. Revise e faça o merge
